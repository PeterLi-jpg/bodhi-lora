# Withdrawn measures

These three files are the outputs of the keyword measures behind values posted in the
discussion: `mimicry_split.json`, `interference_mechanism.json` and
`second_person_questions.json`. Each measure decides what a reply means with a keyword
rule (docs/CONVENTIONS.md rule 15), so the values are withdrawn
(rebuttal/withdrawals.md, W23 to W25). They stay as the record of how the posted values
were made. `make rebuttal` writes them again from `rebuttal/analyses/` and the cell's raw
eval and grade files, which git ignores since 2026-10-11 (history keeps them at 31e4fd8).
The paper reads
none of them (`tests/test_report.py`); the cell's statistics are in `../stats.json`.
